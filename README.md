# STANDARD DETAILS — 店舗ホームページ

カーディテイリング／コーティング専門店「**STANDARD DETAILS**」の新しいホームページです。
オーナーの好みに合わせた **オールドスクール（70's / 80's）レトロ・ガレージ** な世界観で、
「無難すぎる」印象を刷新し、目に留まるデザインにしています。

- 追加のフレームワーク不要の **静的サイト**（HTML / CSS / JavaScript のみ）
- スマホ対応（レスポンシブ）・軽量・そのままどこにでも公開できます
- 実データ（住所・電話・料金など）は後から差し込めるよう **プレースホルダー** にしています

## ✏️ 差し替えが必要な箇所（お店の実データ）

サイト内の **赤い文字**（例：`[電話番号]`）が、あとで入力する場所です。
各HTMLファイル内の `<span class="ph">…</span>` を探して、実際の情報に書き換えてください。

主な差し替え項目：

- **電話番号** … `[電話番号]`、`href="tel:00000000000"` の `00000000000` も実番号へ
- **住所** … `[住所を入力]`
- **営業時間 / 定休日 / 駐車場**
- **料金** … `¥0,000〜` などの金額
- **創業年** … `[創業年]`、`SINCE 'XX`
- **お客様の声 / オーナーメッセージ / オーナー名**
- **LINEのリンク** … `[LINEリンク]` と書かれた `href="#"` を実URLへ
- **統計の数字**（施工台数など）… 実績に合わせて

> Instagram（`@standard_details`）のリンクは設定済みです。

### 写真の入れ方

「📷 …の写真」と表示されている場所が写真の枠です。
`assets/img/` フォルダを作って画像を置き、該当の `<div class="photo-slot">…</div>` を
`<img src="assets/img/ファイル名.jpg" alt="説明">` に置き換えると写真が入ります。
（ヒーローや施工事例に実際の車の写真が入ると、一気に魅力的になります）

## 🎬 オープニング動画

トップページ（`index.html`）を開くと、まず動画がフルスクリーンで再生され、
再生が終わると自動でトップページへ進む「オープニング演出」を入れています。

- **動画ファイル**：`assets/video/opening.mp4`
  差し替えるときは、同じ場所に**同じ名前**で新しい動画を置いてください（形式は
  **MP4 / H.264** 推奨。ほぼ全ブラウザで再生できます）。
- **音声**：ブラウザの仕様で、最初は**ミュートで自動再生**されます。画面右下の
  🔇ボタンで音をオンにできます。
- **操作**：右上「Skip ▶」または下部「▶ Enter Site」でいつでもトップへ進めます。
  動画が終われば自動で進みます。
- **再表示**：一度見たら、同じ訪問（セッション）中は再表示されません
  （ページを行き来しても毎回は流れない設定）。
- **演出をやめたい場合**：`index.html` の `<div class="intro" ...> … </div>`
  ブロックごと削除すれば、動画なしで直接トップが表示されます。
- JavaScriptが無効な環境や検索エンジンには、動画をスキップしてトップページが
  そのまま表示されます（プログレッシブ実装）。

## 📨 予約フォームを実際に動かすには

`contact.html` のフォームは現在 **デモ表示**（送信しても実際にはメールが届きません）。
実際に受信できるようにするには、無料サービスの利用が簡単です：

- **[Formspree](https://formspree.io/)** … `<form>` に送信先URLを設定するだけ
- **Googleフォーム** に置き換える
- メール送信のみで良ければ、電話・LINE・Instagram の導線だけでも運用可能です

## 🚀 公開方法（例）

以下のいずれでも公開できます（すべて静的サイトとして動きます）：

- **GitHub Pages**（無料）… リポジトリ設定から Pages を有効化
- **Netlify / Cloudflare Pages / Vercel**（無料枠）… フォルダをドラッグ&ドロップ
- 既存のレンタルサーバーに FTP でアップロード

ローカルで確認するには、このフォルダで簡易サーバーを立てます：

```bash
# Python があれば
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 🎨 デザインについて

- **配色**：バーントオレンジ × マスタードゴールド × レトログリーン × クリーム × エスプレッソ
- **書体**：Bebas Neue（見出し）／ Alfa Slab One（ロゴ・アクセント）／ DM Sans（本文）
  ※ Google Fonts を読み込んでいます（インターネット接続時に自動適用）
- **質感**：フィルムグレイン、サンバースト、レトロなバッジ枠など 70's / 80's 要素

色をまとめて変えたい場合は `assets/css/style.css` の先頭 `:root { … }` の変数を編集してください。
